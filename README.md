# Omega Education React + Tailwind starter

Run `npm install`, then `npm run dev`. Production build: `npm run build`.

Routes: `/`, `/about`, `/courses`, `/blog`, `/contact`, `/admin`.

Uses React + Vite + React Router + Tailwind CSS v4. Component and page styles are separated into individual CSS files. Replace placeholder course/contact content before publishing.

Important: `/admin` is a UI demo only, without authentication or persistent storage. Connect a secure CMS/backend before real use.
